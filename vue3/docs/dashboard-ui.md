# 首页与我的页面 UI 验收

本次只调整首页、个人中心及首页标题；页面样式使用 scoped，不修改共享导航、全局样式、聊天页面或后端接口。

## 真实数据边界

- 首页现有操作是方向移动、停止、风机开关、风机输出设定。没有新增清扫任务的开始、暂停、继续按钮，因为现有页面调用的接口没有这些操作。
- `deviceService.buildFallbackSummary()` 返回 `mock-rover-001`、87% 电量和 idle；检测到该回退数据或 ROS mock 链路时，概况明确展示演示模式。mock 只修改后端状态缓存，不控制真实设备。
- 在线状态优先采用已开启控制链路的实时 connected；禁用链路不被推断为设备离线。连接与 taskStatus 分开显示。未知枚举不映射为待机。
- 设备真实上报可能没有电量、任务和名称：分别显示暂未收到数据、状态未知、清扫机器人。现有接口未提供可用的单机选择功能，本次沿用原概况接口。
- 页面以 30 秒作为“数据可能过期”的提示阈值。这是页面提示策略，不是硬件故障标准；详细时间保留。延续原 3 秒刷新周期，同时刷新概况、连接和运行数据，避免首屏永久停留在初始记录。
- 风机缓存没有逐字段有效标记和独立运行状态，后端会将缺失字段初始化为零。因此无更新时间显示未收到状态，有更新时间但零值显示“暂未确认（接口缓存为 0）”；运行状态不推断为已关闭。风机输出为 PWM 占空比，不是风速。非零值也只表示接口缓存，不表示命令执行确认。
- 移动接口的 accepted 只表示指令已接受；没有执行确认接口，页面不显示设备已执行。发送失败与正在发送单独反馈，演示命令单独标注。发送期间普通移动禁用，停止入口继续可用，不增加确认弹窗。
- 线速度取 ROS odometry 的 linear.x，单位 m/s；角速度取 angular.z，单位 rad/s。未收到里程计时不展示 store 默认零值。
- 摄像头保留已有图传及流失败转快照机制，图像按原比例显示。未开启或无数据使用紧凑空态，技术配置仅在详情中出现。
- “我的”连接信息展示配置和接入方式，不声称连接正常；退出先确认，再调用原退出逻辑。管理员管理台路由保留。

## 浏览器人工检查步骤

本轮未执行真实浏览器桌面/手机截图验收，也未向真实机器人下发控制命令。以下是仍需人工检查的项目，不能当作已完成的实机验证：

1. 普通用户登录：首屏确认概况、任务、电量；没有重复头像或权限卡；展开三组详情，缺失项不显示已确认正常。
2. 管理员登录：检查移动、停止及风机入口。只在安全测试环境验证发送、失败和演示反馈；停止不受普通移动发送锁限制。
3. 在 390px 手机宽度和 1440px 桌面宽度检查：单列/双列切换、长设备名称、长地址、详情展开及底部导航遮挡。首页最大内容宽度 1200px，个人中心 700px。
4. 未开启摄像头时检查紧凑空态；使用真实可用图传检查图片比例、加载失败及原快照兜底。
5. 对照连接禁用、离线、未知、旧时间戳与 mock 数据检查提示含义。
6. 进入聊天页，确认本轮没有修改其内容、布局与交互。
